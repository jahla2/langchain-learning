# Exploring LangChain & LangGraph

Personal exploration of LangChain and LangGraph — building AI agents with Python.

## Setup

```bash
git clone https://github.com/jahla2/langchain-learning
cd langchain-learning
uv sync
uv run python main.py
```

## Stack

- Python 3.10+
- LangChain v0.3+
- LangGraph
- OpenAI / Anthropic / Ollama
